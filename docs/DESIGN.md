# Steal a Slime [+1 SPEED] — 기획서

## 0. 왜 이 게임을 골랐나 (조사 결과 요약, 2026년 10월 12일 기준)

**조사한 것**
- 지금 동시접속 1위는 **Steal An Egg and Collect Rare Pets** (약 160만 명). 수익 추정도 1위(월 약 1,300만 달러, BloxRant 추정).
  4위 **Break and Steal an Egg**, 9위 **Steal a Brainrot**도 같은 "훔치기 + 알/펫 + 기지 수입" 장르.
- **"+1" 장르**가 동시에 뜨고 있음: *+1 Speed Keyboard Escape*(11위), *+1 Stone Skipping*(27위·급상승), *+1 Loot To Forge*(36위).
  "가만히 있어도 숫자가 1씩 오른다"는 단순한 재미.
- **"~ for Eggs"** 류(*Climb For Animals Eggs*, *Lift Rock For Eggs*)도 50위 안에 여럿. → "알 → 펫 뽑기"는 지금 제일 잘 팔리는 보상 형태.
- 작은 팀이 크게 성공한 예: **Grow a Garden**은 16살 개발자가 며칠 만에 만든 게임에서 시작(최고 동접 2,200만 명).
  **Steal a Brainrot**은 역대 모든 게임 중 최고 동접(2,500만 명). GDC 2026 로블록스 발표: "10명 미만 팀이 동접 2,500만을 찍는다 — 정적인 콘텐츠보다 **사람끼리 엮이는 루프(소셜 루프)**가 핵심".

**결론: "Steal(훔치기) + 알 부화 + +1 스피드"를 합친 게임**
1. 지금 1위·4위·9위 게임이 같은 장르 → 수요가 검증됨. 로블록스는 유행을 빨리 타는 게임이 뜬다.
2. 그대로 베끼지 않고, 따로 뜨고 있는 **+1 스피드** 장르를 섞어서 차별화. "가만히 있어도 1초마다 스피드 +1 → 더 먼 지역 → 더 희귀한 알".
3. 다른 플레이어 기지에서 알을 훔치고, 방망이로 막는 **소셜 루프**가 있음 (GDC에서 말한 성공 공식).
4. 펫을 **슬라임**으로 정한 이유: 도구상자 모델을 못 쓰므로 코드로 직접 만들어야 함. 슬라임은 공 모양 + 눈만으로도 귀엽게 만들 수 있고, 색·크기·장식만 바꿔 수십 종을 만들 수 있다.
5. 혼자(AI 혼자) 만들기에 범위가 적당함. 맵을 코드로 자동 생성할 수 있는 단순한 구조(긴 직선 길 + 지역).

## 1. 한 줄 소개
1초마다 스피드가 +1씩 오른다. 빨라질수록 더 먼 지역에 가서 더 희귀한 **슬라임 알**을 훔쳐 오고, 기지에서 부화시켜 돈을 번다. 다른 사람 기지의 알도 훔칠 수 있다!

## 2. 핵심 루프 (30초 ~ 1분)
1. **스피드 자동 증가**: 어디에 있든 1초마다 스피드 +1 (업그레이드·환생·부스트로 더 빨리).
2. **달리기**: 기지 앞 긴 길을 따라 지역으로 간다. 지역 입구 문은 "스피드 N 이상"일 때만 통과.
3. **알 훔치기**: 둥지의 알에 다가가 버튼(모바일은 터치)을 누르고 있으면 집어 든다. 알을 들면 느려진다.
4. **경비 슬라임 피하기**: 알을 든 채로 경비에 닿으면 알을 떨어뜨림(알은 둥지로 돌아감) + 튕겨나감.
5. **기지로 귀환**: 기지에 들어가면 빈 부화기에 자동으로 들어감. 시간이 지나면 부화.
6. **부화**: 서버가 확률에 따라 슬라임을 정함(확률은 화면에 표시). 슬라임은 받침대에 올라가 **초당 코인**을 만든다.
7. **코인 수거**: 기지의 초록 발판을 밟으면 쌓인 코인을 받는다.
8. **코인 사용**: 스피드 훈련(+초당 스피드), 받침대·부화기 추가, 잠금 시간 증가.

## 3. 중간 루프 (10분 ~ 1시간)
- 다음 지역 문 열기(스피드 목표), 더 좋은 슬라임으로 받침대 채우기, 약한 슬라임 팔기.
- **훔치기(PvP)**: 다른 플레이어 기지의 부화기 속 알을 훔칠 수 있음(완성된 슬라임은 안전).
- **기지 잠금**: 기지의 잠금 버튼 → 일정 시간 동안 아무도 못 들어옴. 끝나면 다시 눌러야 함.
- **방망이(BONK)**: 버튼 하나로 휘두름. 알을 들고 있는 사람을 맞히면 알이 원래 자리로 돌아감.

## 4. 긴 루프 (며칠)
- **환생**: 스피드·코인·훈련 단계를 초기화하는 대신 **영구 배율**(스피드 획득 +50%, 코인 +25%)을 받음. 슬라임·기지 업그레이드는 유지.
- **슬라임 도감**: 처음 얻는 슬라임마다 젬 보상. 황금/무지개 변이 수집.
- **비밀 지역(Void)**: 스피드 50,000 + 환생 2회.
- 매일 출석 보상, 접속 시간 선물, 오프라인 수익.

## 5. 성장 구조 (숫자는 모두 `src/shared/Config.luau` 한 곳에 있음)
| 지역 | 입장 스피드 | 알 | 부화 시간 | 슬라임 수입(초당) |
|---|---|---|---|---|
| 1 Meadow(초원) | 0 | Meadow Egg | 10초 | 2 ~ 40 |
| 2 Forest(숲) | 100 | Forest Egg | 30초 | 12 ~ 900 |
| 3 Desert(사막) | 400 | Desert Egg | 1분 | 80 ~ 7,000 |
| 4 Snow(설원) | 1,500 | Snow Egg | 2분 | 600 ~ 55,000 |
| 5 Volcano(화산) | 5,000 | Magma Egg | 4분 | 4,500 ~ 45만 |
| 6 Crystal(수정 동굴) | 15,000 | Crystal Egg | 7분 | 3.5만 ~ 1,200만 |
| 7 Void(공허, 비밀) | 50,000 + 환생 2 | Void Egg | 10분 | 30만 ~ 1억 |

- 등급: Common / Uncommon / Rare / Epic / Legendary / Mythic
- 변이: 황금(수입 ×2, 기본 4%), 무지개(수입 ×5, 기본 1%)
- 실제 걷는 속도 = `16 + 2 × √스피드` (최대 500). 알을 들면 0.85 ~ 0.55배.
- 목표 진행 속도: 2분 숲 → 10분 사막 → 40분 설원 → 2~3시간 화산 + 첫 환생 → 하루 이상 수정 동굴 → 며칠 Void.

## 6. 화면 (모두 모바일 지원: 크기 비율 기반, 큰 버튼, 키보드 없이 터치로 전부 가능)
- **상단 HUD**: 스피드(크게), 초당 스피드, 코인, 젬, 환생 수.
- **왼쪽 메뉴 버튼**: 상점, 업그레이드, 슬라임(가방), 도감·확률, 환생.
- **오른쪽 큰 버튼**: BONK(방망이), 기지 잠금(남은 시간 표시).
- **팝업**: 부화 결과, 오프라인 수익, 출석 보상, 알림(토스트).
- **월드 표시**: 지역 문 "Need 400 Speed", 둥지 근처에서 알 확률 패널 자동 표시, 알을 들면 기지 방향 빛줄기.
- **튜토리얼**: 처음 접속 시 "알 훔치기 → 기지로 → 부화 → 코인 수거 → 훈련 구매" 안내.

**무과금 균형**
- 모든 현질 효과는 "빨라짐/편해짐"이지 "무과금은 절대 못 얻음"이 아님. 지역·슬라임은 모두 무료로 얻을 수 있다.
- 젬은 출석(7일 주기 10~100), 10분마다 접속 선물(10젬), 도감 첫 발견(2~200젬)으로 무료로 모인다 → 무과금도 Royal Egg·포션 사용 가능.
- 오프라인 수익(25%, 최대 3시간), 완성된 슬라임은 절대 안 뺏김.

**규정 준수**
- 유료 뽑기(Royal Egg)와 행운 상품은 **구매 전에 모든 결과의 확률(%)을 표시**, 합계 100%.
- 행운이 켜져 있으면 표시되는 확률도 실시간으로 바뀜.
- `PolicyService`의 `ArePaidRandomItemsRestricted`가 true인 사용자(일부 국가)는 Royal Egg·행운 상품을 숨기고 서버에서도 막음. 조회 실패 시에도 막음(안전 쪽).
- 결제는 `ProcessReceipt`로 처리: 구매 ID를 플레이어 데이터에 기록 → 저장 성공 후에만 "지급 완료" 응답 → 두 번 지급·미지급 없음.

## 8. 기술 원칙 (해킹 방지·안정성)
- 코인·젬·스피드·레벨·슬라임·뽑기 결과는 **서버만** 정함. 클라이언트는 "이거 하고 싶어요" 요청만 보냄 → 서버가 거리·쿨타임·돈·잠금 상태를 검사.
- 요청 횟수 제한(초당 제한), 이상하게 빠른 이동 감지 시 알 떨어뜨림.
- 데이터: DataStore + **세션 잠금**(다른 서버가 덮어쓰기 방지) + 재시도 + 60초 자동 저장 + 서버 종료 시 저장. 불러오기에 실패하면 빈 데이터로 덮어쓰지 않음.
- 모든 숫자는 `Config.luau` 한 파일.
- 맵·슬라임·UI는 전부 코드로 직접 생성(도구상자 사용 안 함).
